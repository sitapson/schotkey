# Star Citizen telemetry fields

Every field `sc.game.telemetry.v1.GameTelemetryService/TelemetryStream` can send, from the schema extracted from the game exe.

- **Use in SC Hotkey:** pick the path in the *Telemetry field* dropdown, or type it. In lists, replace `N` with 0, 1, 2… (e.g. `weapons.weapons.0.ready_to_fire`).
- **Enums** arrive as full names such as `VEHICLE_COMPONENT_DEPLOYMENT_STATE_DEPLOYED`. In *ON when value is* you can type just the end: `DEPLOYED`.
- **Example** values are from a 49-message recording on LIVE. A blank example means the field wasn't sent then (e.g. no turret seat, no events). Personal values (aUEC balance, entity IDs in names) are removed.
- Generated by `node scripts/list-fields.mjs`. Re-run after a game patch and `npm run extract-schema`.
