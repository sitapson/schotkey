Notes. Read from the schema built into the game, so this lists everything the stream can send. Fields with no example weren't sent during the recording: doors (the Wolf has none), turret (not in a turret seat) and events (only sent when something happens). LIVE's feed has no shield percentage or hull health. Personal values (balance, entity IDs) are removed. Enable with server.game.telemetry.enabled = 1 and grpc.client.server.enabled = 1 in LIVE\user.cfg. Unofficial; CIG hasn't said whether fan tools may use this feed.
